## Process

- 取最新版 0.35.9 → 0.35.11 → 0.35.12。核心 `dist/host/index.d.ts` 注释明确：client 的 `remote.llm` 没有每个 provider 的模型列表，模型只能宿主侧 `llm.listModels(providerId)` 取，旧「读设置镜像 profile.models」路径已废弃且 demo 读不出供应商。
- `src/host/index.ts` apply 接 `serveModelCatalog(ctx as unknown as HostContextLike, { path: MODELS_PATH })`。cordis `Context.inject` 回调签名与 `HostContextLike` 结构声明不符（cordis 把子上下文当 services 传入，运行时等价），故显式断言并注释。
- `src/shared/models-path.ts` 新增，host / client 共用同一 `MODELS_PATH`；`src/client/index.tsx` 改 `connectHost`，删 `DirectoryStore` / `remote.llm` 注入；`src/client/config-panel.tsx` 保存时用 `modelCatalog.getSnapshot().routes` 补首模型，保留原有行为；`src/client/locales.ts` 删 9 个失效键。
- 尺寸核对：核心仓 commit `27708971 分页每页条数下拉开放尺寸档位，bump 至 v0.35.12` 的「开放尺寸」与 `ModelPicker` 主形态无关；cascade 宽度由 `style.ts` flex 约束，传 `width/maxWidth` 反倒会让按钮窄于容器（`flex-basis:0` 覆盖），故不传。
- bug 定位：`ModelPicker.js:99-123` cascade 供应商框 `options` 只有厂商列表、无默认项，模型框 `disabled: provider === ''`，选过具体模型后回不到默认。`ModelPicker.js:72-77` grouped 分支把默认项作为置顶空组头选项，`defaultLabel` 可自定义标题 → 核心已支持，无需改核心。
- 改 `variant="grouped"` + `className="stp-config__model"`；`style.ts` 用 `.stp-config__model{display:block;width:calc(50% - 4px);max-width:calc(50% - 4px)}` + 触发器 `width:100%;min-width:0` 限到原两框之一的宽度、右边留白。
- 发版：`package.json` / `package-lock.json`（顶层 + `packages[""]`）三处 bump `0.8.14`；产物不嵌版本号，故 build 后 `lib/` 无版本 diff。`.github/workflows/publish.yml` 由 push `v*` tag 触发 OIDC `npm publish --provenance`，本地不跑 npm publish。main `56984db`、tag `v0.8.14` 均已推送。
