## Background

触发：用户把 DSH 升级到 `0.2.2-rc.1` 后，于 2026-11-09 反馈两个回归现象。原话：「点那个图标，那个窗口并不出来」「我在输入框里面打斜杠，会出来这么大一堆东西……我不希望这个东西出现到用户能看到的地方……本来用户的注意力就有限，我们这个应该就是一个很静默的东西……这么一个小功能，得不偿失」。

1. **标题旁的编辑图标点了不出弹窗**：会话标题后的铅笔图标，点一下只在下方多出内部命令的回显文本，例如 `title-state` / `unlocked`、`title-suggest` / `1023｜排查｜文件创建失败与路径`；`title-state` / `unlocked` 连着重复多次，说明每点一次就发一次命令，而重命名卡片（`README.md:61-67` 描述的「Rename session」浮层）始终不出现。

2. **内部命令在输入框 `/` 候选里外露**：用户截图列出 6 条 `retitle`、`title-lock`、`title-rename`、`title-state`、`title-suggest`、`title-unlock`，各带一句英文说明，占满候选面板。用户要求这些不许出现在用户能看到的地方。

这些命令本就不是给人手敲的：`src/host/index.ts:524-528` 明确写 `title-suggest` / `title-unlock` / `title-state`「都给设置面板的浮层用，不打算让用户手敲，但注册成命令可以完全复用」；命令名定义在 `src/host/index.ts:41-62`，client 侧发送常量在 `src/client/index.tsx:76-89`，注册入口在 `src/host/index.ts:871-875`。初判怀疑 `0.2.2-rc.1` 改了 slot / 命令契约导致浮层挂不上；2026-11-09 比对两版官方包后已排除，根因见 Process。

约束：插件定位是静默的小功能，不占用户注意力；涉及 DSH 接口先读 `docs/dependencies/` 与宿主包源码实现，不靠真机试错猜 API；两个问题逐个解决、逐个实机验证。

## Process

2026-11-09 根因判定（两版官方包源码比对，未改代码）：

- **API 没被关掉**。`0.2.2-rc.1` 的 `@deepseek-ai/dsh-client-ui-conversation/lib/client.js:22924-22927` 仍声明 `conversation.session.header.actions`（`kind:list, scope:session`），`:20895` 仍 `renderSlot(...)`；`@deepseek-ai/dsh-api-remotes@0.2.2-rc.1/lib/client.js:1258` 仍有 `commands/execute` 契约。背景里「slot 契约被改、浮层挂不上」的初判已排除。
- **按钮和命令都是好的**。点一下执行 `openPanel()`（`src/client/index.tsx:228-238`）：`setOpen(true)` 并发 `/title-state`；会话里那些 `title-state / unlocked`、`title-suggest / 1023｜…` 就是回显。浮层看不见导致反复点，于是命令堆一串。
- **真正原因：上游新增 CSS 裁剪**。`0.2.0-rc.1` 的 `.wSkVaW_titleCluster` 只有 `flex:1;align-items:center;gap:10px;min-width:0;display:flex`（conversation `lib/client.js:15785`）；`0.2.2-rc.1` 变成 `…;mask-image:linear-gradient(...);…;overflow:clip`（`:20057`）。`headerActions` 是 `titleCluster` 的子元素（`:20850`、`:20893-20896`），插件浮层 `position:absolute; top:calc(100% + 6px)`（`src/client/index.tsx:311-318`）整个落在父盒子下方，被 `overflow:clip` 与 `mask-image` 裁掉 —— DOM 在、state 在，只是画不出来。
- 本仓库没有 `docs/dependencies/` 目录，按 DSH 规则直接 `npm pack @deepseek-ai/*@0.2.2-rc.1` 解包读 `lib/*.js`（落 `/tmp`，未入仓库）。本地 `node_modules` 是 `0.2.0-rc.1`，比宿主老。
