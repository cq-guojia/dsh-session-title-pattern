## Background

触发：用户把 DSH 升级到 `0.2.2-rc.1` 后，于 2026-11-09 反馈两个回归现象。原话：「点那个图标，那个窗口并不出来」「我在输入框里面打斜杠，会出来这么大一堆东西……我不希望这个东西出现到用户能看到的地方……本来用户的注意力就有限，我们这个应该就是一个很静默的东西……这么一个小功能，得不偿失」。

1. **标题旁的编辑图标点了不出弹窗**：会话标题后的铅笔图标，点一下只在下方多出内部命令的回显文本，例如 `title-state` / `unlocked`、`title-suggest` / `1023｜排查｜文件创建失败与路径`；`title-state` / `unlocked` 连着重复多次，说明每点一次就发一次命令，而重命名卡片（`README.md:61-67` 描述的「Rename session」浮层）始终不出现。

2. **内部命令在输入框 `/` 候选里外露**：用户截图列出 6 条 `retitle`、`title-lock`、`title-rename`、`title-state`、`title-suggest`、`title-unlock`，各带一句英文说明，占满候选面板。用户要求这些不许出现在用户能看到的地方。

这些命令本就不是给人手敲的：`src/host/index.ts:524-528` 明确写 `title-suggest` / `title-unlock` / `title-state`「都给设置面板的浮层用，不打算让用户手敲，但注册成命令可以完全复用」；命令名定义在 `src/host/index.ts:41-62`，client 侧发送常量在 `src/client/index.tsx:76-89`，注册入口在 `src/host/index.ts:871-875`。初判怀疑 `0.2.2-rc.1` 改了 slot / 命令契约导致浮层挂不上；2026-11-09 比对两版官方包后已排除，根因见 Process。

约束：插件定位是静默的小功能，不占用户注意力；涉及 DSH 接口先读 `docs/dependencies/` 与宿主包源码实现，不靠真机试错猜 API；两个问题逐个解决、逐个实机验证。

## Process

2026-11-09 根因判定（两版官方包源码比对，未改代码）：

- **API 没被关掉**。`0.2.2-rc.1` 的 `@deepseek-ai/dsh-client-ui-conversation/lib/client.js:22924-22927` 仍声明 `conversation.session.header.actions`（`kind:list, scope:session`），`:20895` 仍 `renderSlot(...)`；`@deepseek-ai/dsh-api-remotes@0.2.2-rc.1/lib/client.js:1258` 仍有 `commands/execute` 契约。背景里「slot 契约被改、浮层挂不上」的初判已排除。
- **按钮和命令都是好的**。点一下执行 `openPanel()`（`src/client/index.tsx:228-238`）：`setOpen(true)` 并发 `/title-state`；会话里那些 `title-state / unlocked`、`title-suggest / 1023｜…` 就是回显。浮层看不见导致反复点，于是命令堆一串。
- **真正原因：上游新增 CSS 裁剪**。`0.2.0-rc.1` 的 `.wSkVaW_titleCluster` 只有 `flex:1;align-items:center;gap:10px;min-width:0;display:flex`（conversation `lib/client.js:15785`）；`0.2.2-rc.1` 变成 `…;mask-image:linear-gradient(...);…;overflow:clip`（`:20057`）。`headerActions` 是 `titleCluster` 的子元素（`:20850`、`:20893-20896`），插件浮层 `position:absolute; top:calc(100% + 6px)`（`src/client/index.tsx:311-318`）整个落在父盒子下方，被 `overflow:clip` 与 `mask-image` 裁掉 —— DOM 在、state 在，只是画不出来。
- 本仓库没有 `docs/dependencies/` 目录，按 DSH 规则直接 `npm pack @deepseek-ai/*@0.2.2-rc.1` 解包读 `lib/*.js`（落 `/tmp`，未入仓库）。本地 `node_modules` 是 `0.2.0-rc.1`，比宿主老。

- **2026-11-09 修复（第一个问题，未实机验收）**：`src/client/index.tsx` 把浮层改成 `createPortal(..., document.body)` + `position:fixed`，定位走 `wrapRef.getBoundingClientRect()`，左缘对齐 `_crumbCurrent`、右缘守视口（`src/client/index.tsx:196-241`、`:324-413`）；点外部收起同时判 `wrapRef` 与 `panelRef`，并监听 `resize` / `scroll` 重算位置。`react-dom` 在 `tsdown.client.config.ts:24` 的模块表里，宿主官方包自己也这么用（`dsh-client-ui-primitives/lib/index.js:17`）；本地缺 `@types/react-dom`，补 `src/client/react-dom.d.ts` 最小声明，未装依赖。
- 验证：`npm run build` 通过、`npm run typecheck` 退出码 0、`node --check lib/client.js` 通过；产物 `lib/client.js:30` 保留 `require("react-dom")`（未被内联），`:877` / `:1009` 是 `createPortal(..., document.body)`。
- `koc-codelint` 告警已清零（用户要求修到 0 警告）：74 条全在构建产物 `lib/client.js`（逗号运算符 / var / 单次赋值），源码与 `.d.ts` 零告警；`HEAD:lib/client.js` 同样有这些模式（360 处），属 rolldown 既有生成代码。生成物不手改（下次 build 会覆盖），改为在项目根加 `biome.json`：`files.includes: ["**", "!lib"]` 把生成产物排除出 L1；规则集逐条搬自通用基线（`biome migrate` 把弃用的 `recommended` 换成等价的 `preset: "recommended"`），源码检查强度不减。`koc-codelint/scripts/codelint.py:245-271` 的「项目有配置就尊重项目」是该脚本支持的正规路径。复跑结果：`[summary] 检查通过｜5 个文件｜六层全过`、退出码 0；`biome lint src/client/index.tsx src/client/react-dom.d.ts` 仍报 Checked 2 files，`lib/client.js` 明确被忽略。

- **2026-11-09 纠错：上轮提的「插件私有 `TypertRemoteService`」方案不可行，予以否掉**。`dsh-api-remotes/lib/client.js:13264-13296` 的 `apply` 把 24 个**编译期生成**的契约常量逐个 `ctx.remote.$mount(...)`，第三方插件 namespace 不在其中，运行时不动态发现；宿主公开的 132 个远程方法分布在 28 个命名空间里，全是宿主自带能力。`session` 只有 `rename`/`projections` 等，`llm` 只有 `discoverModels`/`listConfigurableProviders`/`listProviders`，`commands` 只有 `execute`/`list`；`session.projections` 的 `title` 是 `string | null`、不带来源（`lib/client.js:10731`），所以「锁定态查询 / 解锁 / 调 LLM 草稿」都无法搬到客户端。`CommandRegistry.register`（`dsh-commands@0.2.2-rc.1/lib/index.js:266-268`）只是 `layers.effect(... layer.commands.insert(name, registered))`，`list`（`:424`）是 `layers.merge(agent, ...)`，没有 hidden / 不可发现层。结论：**0.2.2-rc.1 的宿主能力下，「6 条命令零出现 + 现有面板功能全保留」没有正规实现**；硬让私有 namespace 生效需手写宿主内部契约或改宿主包，那正是用户要避开的「走后门」。

## Conclusion

弹窗被上游 CSS 裁剪的问题已在源码与产物层面修好、基础代码检查告警清零、发版 `0.8.10`；用户实机确认弹窗已出现。第二个问题（斜杠命令外露）确认无官方隐藏开关，上轮方案已否掉，代价与取舍待用户拍板。
