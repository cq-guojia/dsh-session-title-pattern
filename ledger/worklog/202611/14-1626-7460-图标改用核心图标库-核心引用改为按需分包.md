### 二、核心图标库事实（0.35.28 实测）

- `ICON_FONTS` 共 5 套：`common.base`、`common.base.color`、`common.logo`、`common.logo.color`、`dsh-plugin-core.base`（`src/ui/display/font-icon.ts:54`）。
- **`dsh-plugin-core.base` 目前是空库**：在线 CSS 里只有一个占位字形 `_`（`https://at.alicdn.com/t/c/font_5252865_zv3n1s2zg3e.css`）。所以「核心自有图标」实际只能用 `common.base`，它当前有 57 个名字（拉取 `font_5252971_jpekkiqjy2.css` 解析），其中含 `xiugai` / `guanbi` / `lianjie`；`common.logo` 有 `wechat` / `npm` / `github` / `deepseek` 四个品牌字形（`font_5252974_y0yj8zp5mvm.css`）。
- 图标尺寸口径：不传 `size` 就跟随所在文字字号；本次三处都不传（原先写死 16），与核心控件一致。

### 三、物理切割（0.35.28 的 exports）

- `package.json` 的 `exports` 由 **11 条 → 63 条**，新增 52 个 `./ui/*` 子路径（`icons` / `button` / `input` / `chip` / `model-picker` / `host-data` / `styles` …），`./ui` 聚合入口仍在。
- 本插件 3 处 `dsh-plugin-core/ui` 已改子路径：`index.tsx`（`ui/button`、`ui/input`、`ui/styles`、`ui/host-data`、`ui/icons`）、`config-panel.tsx`、`model-pair.tsx`。`dsh-plugin-core/design` 与 `dsh-plugin-core/host` 本来就是子路径，未动。

### 四、体积实测（改前 / 改后）

| 指标 | 改前（0.35.25 + 聚合入口） | 改后（0.35.28 + 子路径） |
|---|---|---|

## Conclusion

- 三处图标全部有核心对应项，**没有缺失**：头部铅笔 `common.base:xiugai`、卡片关闭 `common.base:guanbi`、设置区两个外链按钮 `common.logo:github`。
- 手绘内联 SVG、官方命名空间兜底链、`import * as primitives` 一并删除；`config-panel` 也不再直接引官方图标组件。

- 核心引用从 1 个 `ui` 聚合入口改为 8 条子路径，跟住 0.35.28 的物理切割。
- 用户 2026-11-15 实机验收通过（三处字形正常，外链按钮按反馈改用 GitHub 品牌 logo），随 **v0.8.19** 发版。
